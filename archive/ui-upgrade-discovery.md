# 🎨 UI/UX & Animation Upgrade — Discovery Questionnaire

Answer these questions so we can build a precise, opinionated upgrade plan for your project. Be as specific or as brief as you like — any detail helps.

---

## 1. Project Overview

- **What does the app do?** (e.g., task manager, dashboard, e-commerce, SaaS tool)
- **Who are the primary users?** (developers, general public, business clients, etc.)
- **What's the current tech stack?**
  - React version?
  - Node/Express, Fastify, or other backend?
  - Any CSS framework already in use? (Tailwind, MUI, Chakra, plain CSS, etc.)
  - Any animation library already installed? (Framer Motion, GSAP, etc.)

---

## 2. Current UI State

- **What does the app look like right now?** (plain/functional, half-styled, almost done?)
- **Are there any screenshots or a live URL you can share?**
- **What's the single biggest visual problem you want fixed?**
- **What parts of the UI feel the most "unfinished" or "cheap"?**

---

## 3. Desired Look & Feel

- **Pick words that describe the vibe you want:**
  - [ ] Clean & minimal
  - [ ] Bold & modern
  - [ ] Soft & approachable
  - [ ] Dark & professional
  - [ ] Playful & energetic
  - [ ] Luxury / premium
  - [ ] Other: ___________

- **Any apps, websites, or design systems you admire?** (even unrelated industries are fine — e.g., "I like how Linear feels", "something like Stripe's docs")

- **Light mode, dark mode, or both?**

---

## 4. Animations & Motion

- **What kind of animations do you want?**
  - [ ] Page transitions (route changes feel smooth)
  - [ ] Micro-interactions (buttons, toggles, inputs respond to hover/click)
  - [ ] List/card entrance animations (items fade or slide in on load)
  - [ ] Loading states (skeletons, spinners, progress bars)
  - [ ] Scroll-triggered reveals
  - [ ] Modal / drawer open-close animations
  - [ ] Other: ___________

- **How subtle or expressive should motion be?**
  - [ ] Very subtle — barely noticeable, just "feels alive"
  - [ ] Moderate — visible but not distracting
  - [ ] Expressive — confident, memorable motion

- **Any animation styles you specifically dislike?** (e.g., "no bouncy effects", "no slow fades")

---

## 5. Performance Constraints

- **Is bundle size a concern?** (e.g., targeting mobile users on slow connections)
- **Are there performance budgets or Lighthouse score targets?**
- **Any devices or browsers that must be supported?** (older Safari, Android WebView, etc.)
- **Is server-side rendering (SSR) or static generation involved?** (Next.js, etc.)

---

## 6. Scope & Pages

- **How many pages/routes does the app have?** (rough number is fine)
- **Which pages get the most user attention?** (home, dashboard, detail view, etc.)
- **Are there any pages or components that are out of scope for this upgrade?**

---

## 7. Component Inventory

Check any components that exist and need upgrading:

- [ ] Navigation / sidebar / topbar
- [ ] Buttons & CTAs
- [ ] Forms & inputs
- [ ] Cards / list items
- [ ] Tables / data grids
- [ ] Modals / dialogs
- [ ] Toasts / notifications
- [ ] Charts / data visualizations
- [ ] File upload UI
- [ ] Auth screens (login, register)
- [ ] Empty states / error pages
- [ ] Other: ___________

---

## 8. Branding & Design Tokens

- **Is there an existing brand color palette?** (hex codes if you have them)
- **Is there a logo or brand identity to match?**
- **Any fonts already chosen, or is typography open?**
- **Do you want a consistent design token system set up?** (CSS variables or a theme file)

---

## 9. Deliverables & Handoff

- **What do you want as output?**
  - [ ] A full upgrade plan document (step-by-step)
  - [ ] Ready-to-use code snippets / components
  - [ ] A reusable animation utility/hook library
  - [ ] Refactored existing files
  - [ ] All of the above

- **Will you be implementing changes yourself, or is this going to another developer?**
- **Any deadline or phasing in mind?** (e.g., "want core animations in one week, rest later")
